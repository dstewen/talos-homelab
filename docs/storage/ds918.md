# Synology DS918+

The [Synology DS918+](https://www.synology.com/en-global/support/download/DS918+) is a desktop
NAS appliance from Synology.

## Hardware

- **Form Factor**: 2U rackmount, 21" deep (short-depth)
- **CPU**: Intel Celeron J3455, 4-core
- **RAM**: 8GB
- **Drive Bays**: 4x 3.5" and 2x NVME (cach only)
- **Networking**: 2x 1GbE RJ45 (onboard)

## fairy-store01

fairy-store01 is the Synology DS918+ at the fairy site.
It provides bulk media storage, Veeam Agent backups, and SMB shares for the
home network.
There is a Pi-hole v5 container running on it that provides DNS to the internal network.
A Minio container provides a S3 bucket for volsync backups

### Storage Layout

- **Drives**: 4x 9.1TB WD Red (WD102KFBX-68M95N0) 2x 500GB (WD_BLACK SN770 500GB)
- **Storage Layout**: 1x 27.3TB volume for data, 2 x 500GB NVME for cache

### Network

- **Uplink**: 1G copper to fairy-r02-tor01 (Netgear XS724EMv2)

### Uses

- Media libraries (Plex, Jellyfin) via NFS exports to Kubernetes
- Veeam Agent backups of gaming rig
- SMB shares for general file storage
- Pi-hole DNS
- S3 for volsync backups of kubernetes cluster
