# topf Migration Workspace

This directory is a sandbox for migrating the `talos-homelab` repository from `talhelper` to `topf`.

## Directory Structure
- `data/`: Structured YAML files containing cluster and node-specific data.
- `templates/`: `topf` templates for rendering Talos configurations.
- `output/`: The rendered `.yaml` files that will eventually be committed to the main repo.
